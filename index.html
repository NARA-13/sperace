SPERACE

101 cells · one egg · one golden crown.

The game is a Godot 4 WebAssembly build and browsers refuse to load .wasm from file://, so serve the folder over HTTP:

cd SPERACE && python3 serve.py

Try Web_Build/index.html Read the README

If the button above shows a blank screen, start the local server (or upload Web_Build/ to any static host) and reload.
